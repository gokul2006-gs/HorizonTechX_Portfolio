# Gokul S – Personal Portfolio

A clean, responsive personal portfolio website built with HTML, CSS, and JavaScript.

🔗 **Live Demo:** [HorizonTechX Portfolio](https://gokul2006-gs.github.io/HorizonTechX_Portfolio)

## Sections

- **Hero** – Introduction with photo, bio, and social links
- **Skills** – Technologies and tools
- **Experience** – ML Internship details
- **Projects** – Fleet IQ & Smart Vehicle System
- **Certifications** – Awards and training
- **Education** – Academic background
- **Contact** – Contact form and details

## Tech Stack

- HTML5
- CSS3 (custom, no frameworks)
- Vanilla JavaScript

## Features

- Dark theme with purple accent
- Smooth scroll & scroll-triggered animations
- Hover effects on all cards
- Responsive layout with mobile hamburger menu
- Active nav highlight on scroll

## Setup

1. Clone the repo
   ```bash
   git clone https://github.com/gokul2006-gs/HorizonTechX_Portfolio.git
   ```
2. Add your photo as `photo.jpg` in the root folder
3. Open `index.html` in your browser
